# Model directory

Place model files here:

```text
models/
  detector/face_detection_yunet_2023mar.onnx
  recognition/w600k_r50.onnx
  liveness/2.7_80x80_MiniFASNetV2.onnx
```

Run `scripts/install-models.ps1` to fetch them.

The public InsightFace model pack has a non-commercial-research restriction according to its current documentation. Obtain a suitable commercial license/model before any production banking use.
